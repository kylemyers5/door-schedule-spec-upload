# AI Door Schedule & Spec Extraction Tool

A functional prototype designed to automate the extraction of unstructured data from architectural PDFs, door schedules, and technical specifications, streamlining the commercial construction takeoff process.

## Overview
Manual blueprint takeoffs and door schedule reviews are time-consuming and prone to human error. This tool provides a clean interface to upload project documents, leverage AI-driven parsing, and extract structured data to accelerate project estimating and workflow efficiency.

## Tech Stack
* **Frontend:** HTML5, CSS3 (Responsive UI, custom gradients, clean container architecture)
* **AI / Parsing Logic:** LLM integration for unstructured document processing
* **Version Control:** Git / GitHub

## Key Features
* Drag-and-drop or file upload interface for architectural specs and schedules.
* Structured data formatting to bridge PDF documents with downstream estimation or CRM workflows.
* Clean, minimalist UI designed for low-friction operational use.
